# Feature: Account Search

The dashboard account list searches across account context, not only handles.

On X, Contexto also provides a local saved-account search directly above X's native right-sidebar search. It fuzzy-matches only saved X display names and handles, shows up to five results, and opens a selected profile in the current tab. It never changes or searches X's native field.

Search currently matches:

- Handle.
- Display name.
- Company.
- Role.
- Location.
- Relationship source.
- Latest note text.
- Tag names.
- Folder names.

Dashboard filters also support narrowing by folder, tag, and company.
